3-Minute Winning Pitch Script + Demo Flow (Finalist Style)

0:00–0:20 | Hook
"Hi judges — this is Nexus Mind Vault.
People want AI help for reflection, but they don’t want their most private thoughts exposed.
So we built a zero-knowledge cognitive mirror: your journal is encrypted first, AI is user-controlled, and privacy is not optional."

0:20–0:45 | Problem
"Today’s journaling and AI apps force a tradeoff:
- either great intelligence with weak privacy,
- or private notes with no intelligence.

For users handling sensitive reflections, that tradeoff is unacceptable."

0:45–1:10 | Solution
"Nexus Mind Vault combines:
1) Encrypted journaling,
2) AI reflection assistant,
3) Semantic memory intelligence — graph + day-wise heatmap timeline.

All in one secure workflow."

Live Demo Flow (what to click, what to say)

1:10–1:35 | Secure unlock + trust
- Open unlock screen.
- Enter secret code.
- Say:
  "Access requires secret-code unlock. We intentionally separated sensitive unlock behavior and removed conflicting biometric shortcuts on this screen to preserve security intent."

1:35–2:00 | Capture + AI assist
- In Capture Studio, type a short reflection.
- Click Send to AI.
- Say:
  "AI gives reflective guidance, but user controls AI access. If AI is disabled, air-gap rules block requests."

2:00–2:25 | Realtime voice interaction
- In Chat tab, click Start Voice, speak one sentence, click Stop Voice.
- Show transcript and AI reply.
- Say:
  "Voice supports SpeechRecognition with MediaRecorder fallback, so it works across browsers and still degrades gracefully."

2:25–2:45 | Intelligence views
- Open Semantic Graph and click a node.
- Show Associated Reflections.
- Say:
  "This is not decorative visualization — each concept node opens linked encrypted reflections, turning memory into actionable insight."

2:45–3:00 | Calendar + close
- Open Chronicle Calendar view.
- Show day-wise heatmap-lite and selected day entries in DD-MM-YYYY.
- Close with:
  "Nexus Mind Vault is where privacy, AI, and personal cognition coexist.
  We’re not asking users to trade security for intelligence anymore."

Final 1-line closer (memorize this)
"Nexus Mind Vault makes private thinking AI-powerful — without surrendering ownership of the mind."
